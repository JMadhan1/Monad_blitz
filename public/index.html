The gap this fills

AI agents already pay for things autonomously on Monad — but nothing checks whether an agent was authorized to spend that amount before the payment settles. Put the limit on-chain in plaintext and you leak a business's entire budget to every competitor watching the chain. So this hides the number instead.

1

Commit

The owner picks a spend limit — say 1000 — and commits Poseidon(secretKey, 1000, owner) on-chain. Only the hash is written. The 1000 is never stored anywhere on-chain.

2

Prove

Before paying, the agent generates a Groth16 zero-knowledge proof of one statement: "the amount I'm requesting is within the limit I committed to." The limit itself never appears in the proof.

3

Verify or block

The contract checks the proof (~250k gas) and allows the payment. Request more than the hidden limit and no valid proof can even be generated — it's rejected before it ever reaches the chain.
